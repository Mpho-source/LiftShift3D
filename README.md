# LIFT / SHIFT 3D

A first-person 3D elevator simulation game developed using Godot 4 and GDScript.

## About the Project

LIFT / SHIFT 3D is a game development project focused on building an interactive elevator system inside a 3D environment.

Players can explore a building, interact with elevator controls, travel between floors, and complete simple rescue missions.

The project is currently in development, with a focus on improving gameplay, graphics, and overall performance.

## Features

- First-person player movement
- Walking, sprinting, and jumping
- Mouse-controlled camera
- Interactive elevator doors
- Elevator movement between floors
- Floor selection and elevator call buttons
- 3D building environment
- Basic lighting and metallic materials
- VIP rescue missions
- Mission timer and scoring system

## Technologies Used

- **Game Engine:** Godot 4
- **Programming Language:** GDScript
- **Graphics:** Godot 3D rendering
- **Physics:** Godot built-in physics engine

## Controls

| Key | Action |
|---|---|
| W, A, S, D | Move |
| Mouse | Look around |
| Shift | Sprint |
| Space | Jump |
| E | Interact with elevator controls |
| F | Rescue VIP |
| 1 / 2 | Select elevator floor |
| Esc | Release mouse cursor |

## Getting Started

1. Download or clone this repository.
2. Open Godot 4.
3. Select **Import**.
4. Locate and select `project.godot`.
5. Open the project and press **F5** to run.
